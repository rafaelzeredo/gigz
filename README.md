# GigZ

Official website of **GigZ**, a power trio from Brasília formed in 2026: https://rafaelzeredo.github.io/gigz/

A static site with no build step for visitors. GitHub Pages serves this folder from `main`.

- **`index.html`** is generated by `build.py` from `index.src.html`. The script fills in the set list, video cards, gallery and structured data from the real media files. To change the page, edit `index.src.html` and run `python3 build.py`.
- **`assets/css/site.css`** and **`assets/js/site.js`**: styles and behaviour (no frameworks).
- **`assets/brand/`**: the GigZ wordmark (SVG paths, Bricolage Grotesque condensed ExtraBold, with an ember Z) and the icons.
- **`assets/img/`**: graded photos from the band photo session of 7 July 2026, the musician crops and the share image.
- **`assets/video/`**: web versions of the Garden Session films (22 July 2026), the hero loops and the posters. "Isn't She Lovely" is a ~55 s excerpt.

Media production files live outside this repository, in `~/Desktop/ClaudeWorkspace/GigZ/`:
- **`docs/`**: the inventory, song map and decisions.
- **`work/scripts/`**: the production scripts.
- **`exports/master/`**: the video and audio masters.

The original camera files on the external drive were only read, never changed.
